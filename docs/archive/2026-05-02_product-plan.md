# 総合型選抜ナビサイト「AOナビ」構成書

> このドキュメントは、KYUTE合同会社が運営する総合型選抜メディア **「AOナビ」** を制作するための指示書です。
> 参考：[年内入試ナビ](https://nennai-nyushi-navi.jp/) / [塾選](https://bestjuku.com/)

---

## 1. サイトコンセプト

> **「総合型選抜（旧AO入試）に特化した、年内入試マッチング × 対策塾検索 × ノウハウメディア」のハイブリッドポータル**

- 高校生が以下を **ワンストップ** で見つけられる：
  - 自分に合う **大学**
  - 自分に合う **塾**
  - 自分に合う **対策法**
- KYUTE本体（コーポレート）とは **別ブランド**。高校生に親しみやすい軽快なデザイン
- 最終的には KYUTE の塾／AI への送客導線も持つ

## 2. ターゲット

| 区分 | 想定読者 | サイト上のゴール |
|---|---|---|
| 主 | 高校 1〜3 年生（特に 2〜3 年） | 大学検索・塾比較・診断 → 資料請求／会員登録 |
| 副 | 保護者 | 子どもに合う進路発見・コラム閲覧 |
| 副 | 高校教員・進路指導 | 進路情報の参照 |
| クライアント | 大学・塾 | 掲載 → リード獲得 |

## 3. ビジネスモデル

- 大学からの **掲載・資料請求課金**（リード型）
- 塾からの **掲載・体験申込課金**
- **記事広告／タイアップ**
- 会員データを基盤にした **LINE／メール配信広告**
- KYUTE自社サービス（塾／AI）への **クロスセル**

## 5. ページ構成詳細

### 5.1 共通要素

#### ヘッダー
- ロゴ「AOナビ」
- ナビ：大学を探す / 塾を探す / 入試を探す / コラム / 体験記 / 診断
- 右：**資料請求（無料）** / 会員登録 / ログイン
- スマホ：ハンバーガー、下部固定の「診断する」CTA

#### フッター
- サービス：大学を探す / 塾を探す / オープンキャンパス / 入試対策
- 受験情報：総合型選抜 / 学校推薦（公募・指定校）/ 一般選抜
- 運営情報：運営会社「KYUTE合同会社」/ 利用規約 / 個人情報 / 問合せ
- SNS：LINE / X / Instagram / TikTok
- LINE 友だち登録 CTA

### 5.2 トップページ（`/`）

1. **Hero**
   - キャッチ：「あなたの『総合型選抜』を、最短ルートで。」
   - サブ：全国◯大学 / ◯塾 / ◯記事から、自分に合う合格戦略が見つかる
   - 検索ボックス（キーワード / エリア / 学問）
   - メインCTA：① 合格力診断を受ける ② 大学を探す
2. **5つの切り口で大学を探す**（年内入試ナビ準拠）
   - エリア / 学問 / 職業 / 評定平均 / 入試方式
3. **総合型選抜とは？ 3STEPガイド**（初心者向け）
4. **注目大学ピックアップ**（編集 + PR枠）
5. **注目の対策塾**（オンライン / 個別 / 集団）
6. **最新合格体験記**（カルーセル）
7. **お役立ちコラム**（カテゴリタブ：総合型選抜 / 公募 / 志望理由書 / 小論文 / 面接 / 学部別）
8. **合格者インタビュー**
9. **無料資料請求 / プレゼント** CTA
10. **オープンキャンパス情報ピックアップ**
11. **メルマガ／LINE登録**
12. **運営会社紹介**（KYUTEの塾／AIを軽くクロスセル）

### 5.3 大学を探す（`/universities`）

- **検索条件**：地域 / 学問 / 職業 / 偏差値・評定 / 入試方式 / 学費 / 特徴タグ
- **並び順**：人気 / 新着 / 評定下限が低い順 / 出願締切が近い順
- **一覧カード**：
  - ロゴ + 名称 + 所在地
  - 学部数 / 入試方式数 / 評定目安 / 直近締切
  - 「資料請求」「詳細を見る」「比較リスト追加」

### 5.4 大学詳細（`/universities/[slug]`）

- ヒーロー：大学名 / メイン画像 / 公式サイトリンク
- 基本情報：所在地・学部・偏差値・評定平均目安
- **年内入試マトリクス**：学部 × 入試方式
  - 出願期間 / 試験内容 / 評定要件 / 募集人数
- 過去問題傾向 / 提出物（志望理由書文字数等）
- 合格体験記（同大学）
- 関連コラム
- **対策に強い塾**（広告枠）
- 資料請求 CTA / オープンキャンパス情報

### 5.5 対策塾を探す（`/juku`）

- 検索：地域 / 駅 / 授業形式 / 対象学年 / 対応入試（総合型・公募・小論文・面接）/ オンライン可否
- **総合型選抜向け塾ランキング**（エリア別 / 形式別 / 目的別）
- 塾カード：ロゴ + 名称 + キャッチ + 対応形式 + 特徴タグ + 口コミ評価 + 「資料請求 / 無料体験 / 口コミ」

### 5.6 塾詳細（`/juku/[slug]`）

- ヒーロー：塾ロゴ・代表写真・キャッチ
- 強み3点 / コース・料金 / 講師紹介 / 合格実績
- 口コミ一覧（フィルタ：学年 / 目的 / 評価）
- 教室一覧 / オンライン対応有無
- 体験申込・資料請求 CTA

### 5.7 年内入試を探す（`/admission`）

- 入試方式タクソノミー：総合型選抜 / 学校推薦型（公募・指定校）/ AO継続枠
- **出願締切カレンダー**（月別）
- スケジュール早見表
- 大学 × 入試方式 横断検索

### 5.8 合格力診断（`/diagnosis`）

- 5〜10問（評定 / 強み / 興味学問 / 通学エリア / 重視ポイント）
- 結果：
  - 「**いま狙える大学**」「**少し頑張れば届く大学**」（年内入試ナビ準拠）
  - 結果に紐づく対策塾サジェスト
  - 結果保存には会員登録 → 資料請求動線

### 5.9 コラム（`/column`）

- カテゴリ：
  - 総合型選抜 基礎
  - 志望理由書の書き方
  - 小論文対策
  - 面接対策
  - 学部・学問解説
  - 大学別対策
  - 親御さま向け
  - 不登校・進路の悩み
- 一覧 + サイドバー（人気記事 / カテゴリ / 関連大学）
- 詳細：目次 / 著者プロフィール / 関連記事 / 資料請求 CTA

### 5.10 合格体験記（`/experience`）

- 一覧：大学別 / 学習開始時偏差値 / 入試方式 / 学習開始学年
- 詳細：
  - 受験者プロフィール、合格大学、利用塾
  - スケジュール（高1からの逆算）
  - 志望理由書のポイント、面接で意識したこと
  - 後輩へのメッセージ

### 5.11 合格者インタビュー（`/interview`）

- 編集チームによる長尺取材記事
- 写真・引用・タイムライン構成

### 5.12 オープンキャンパス（`/event`）

- 大学別カレンダー
- オンライン / 対面フィルタ
- 申込み導線

### 5.13 会員機能（`/mypage`, `/signup`, `/login`）

- マイページ：気になる大学・塾リスト / 診断結果履歴 / 資料請求履歴 / LINE 連携
- 登録特典：「総合型選抜 オリジナル資料」プレゼント

### 5.14 資料請求（`/resource-request`）

- 大学・塾 横断のまとめ請求
- 1フォームで複数校に送信

### 5.15 運営会社（`/about`）

- KYUTE合同会社の紹介
- KYUTEの個別指導塾 / AI への送客

## 6. デザイントークン

### コンセプト
- KYUTE本体とは別ブランド
- **明るい・親しみやすい・スマホで読みやすい**

### カラー
| Token | 用途 |
|---|---|
| プライマリ | 明るいブルー（信頼） |
| アクセント | オレンジ or イエロー（行動喚起） |
| サブ | パステル系 |

### フォント
- Noto Sans JP
- 見出しは太め（700〜800）

### スタイル
- イラスト：手書き風 + フラットの組合せ
- カードUI、丸み大きめ（16〜24px）
- ドット背景・吹き出し・チップなどポップな装飾
- **モバイルファースト**

## 11. KYUTE本体との関係

- **相互送客**：
  - AOナビ → KYUTE塾／AI（記事末・サイドバー・大学詳細から）
  - KYUTE → AOナビ（フッター・Servicesセクション）
- **データ連携**：
  - AOナビの会員 → KYUTE塾の体験申込導線
  - KYUTE生徒の合格体験記 → AOナビ掲載で資産化
- **ブランド分離**：
  - KYUTE：知性的・落ち着いた深紺
  - AOナビ：親しみやすい明るいブルー + アクセントカラー
